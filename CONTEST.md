# Публичный вызов: сломай капчу из движущихся точек

## Что дано

- Полный исходник генератора (`generator/`) — параметры, шрифт, тайминги и режимы (`classic` / `jelly`) открыты.
- Набор из 10 GIF с метками (`samples/`) — для локальной отладки.
- Закрытый набор (100 GIF) для финального замера — по запросу у автора.
- Веб-приложение (.NET + Rust) — живая трансляция кадров: готовый файл не отдаётся, поле открывается при наведении.

## Цель

Решатель, который по ОДНОМУ файлу GIF выдаёт 4 цифры.
- Разрешено: любые алгоритмы, CV, ML, обучение на самостоятельно
  сгенерированных данных (генератор открыт — можно генерировать сколько угодно
  примеров), любые языки.
- Запрещено: читать ответ из файла/метаданных, использовать метки закрытого
  набора, человеко-фермы (кроме отдельной категории «human + tool»).
- Ограничение по времени на один GIF: 30 секунд (столько живёт challenge).

## Метрика

Доля точных 4-значных совпадений на закрытом наборе из 100 GIF.
Ориентиры: эталонный CV-решатель = 0/50; сильный CV-решатель (усреднение фона + EM) = 66–83% на исходной версии и 0% на текущей; лучший честный результат сообщества = 4/100. Порог «капча сломана» = 50%. Полная хроника: `docs/ATTACK-HISTORY.md`.

## Как участвовать

1. Форкните репозиторий/скопируйте генератор.
2. Напишите решатель, прогоните на своих данных.
3. Пришлите: код решателя, команду запуска и результат на закрытом наборе
   (автор прогонит его сам, чтобы исключить подгонку под метки).

## Что будет с результатами

- Публичное признание автора решения (имя/ник в README).
- Если капча ломается — фиксируем это как результат стойкости и указываем,
  какие параметры потребовалось поменять, чтобы её закрыть.
